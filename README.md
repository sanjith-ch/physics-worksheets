# IBDP Physics By Sanjith Chellamuthu

Revision site for IB Physics: every worksheet question sorted by theme (A to D) and sub unit, with hidden model answers, done and review marks, a progress tracker and an exam countdown.

## Files

- `index.html` is the whole site (questions data, answers, styles and script).
- `q/` holds one image per question, cropped from the worksheets.

## Hosting on GitHub Pages

Settings, then Pages, then set Source to "Deploy from a branch", branch `main`, folder `/ (root)`.

Progress is stored in the browser you use (localStorage), so it does not carry over between devices.

The question images come from school worksheets and past papers. Keep the repository private unless you have permission to share them.
